# Stealth Lock
A screen lock for the GNOME Shell inspired by xtrlock. This extension gives you an alternative way of locking your screen beside using GDM.

The main idea comes from xtrlock, but that package only works for X11 session. Since I am a hardcore GNOME user, I decided to develop an extension for the GNOME Shell that can achieve the same thing (and more, hopefully).

## Why?
I like locking my screen, but I don't like having my system going to a different screen to do it. So instead of a lock screen, I want a screen lock.

## Co-developed with LLMs
This project is co-developed with LLMs. However, no LLM code goes through untested, verified, nor accepted without proper manual research. Human maintainers are responsible for their contributions regardless of machine help.

Developing a GNOME Shell extension is a knowledge I do not possess prior to this project, and even with the LLM assist. I do not take any of their output as a point of truth, but only as speculations.

If you are a GNOME Shell extension developer, I'd love for you to take a look, and point out things that can be improved!
