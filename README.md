# Stealth Lock
A screen lock for the GNOME Shell inspired by xtrlock. This extension gives you an alternative way of locking your screen beside using GDM.

The main idea comes from xtrlock, but as the name suggests, it only works for X11 session. So I decided to develop an extension for the GNOME Shell that can achieve the same thing on both X11 and Wayland sessions, but it has then become its own thing with more features.

## But why?
There's a lot of reasons why, depends on your use case.

One good reason is to simply lock the KBM while having the display running. This has reasons within reason, maybe you're playing a media (like movie or music) but don't want your any inputs messing it up (like skipping, changing volumes, or accidentally minimize), then this is a good solution for it.

Another reason is if you want to have a different custom lock screen, you can do that with Stealth Lock too.
